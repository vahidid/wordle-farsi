# واژه‌چین (Wordle فارسی) 🎯

پروژه مدرن بازی **واژه‌چین (Wordle فارسی)** پیاده‌سازی شده با **Next.js 16 (App Router)**، **TypeScript**، **Tailwind CSS v4**، دیتابیس و احراز هویت رایگان **Supabase** و آماده برای استقرار فوری در **Vercel**.

---

## ✨ ویژگی‌های کلیدی

- **فرهنگ واژگان غنی فارسی:** دارای بیش از ۱,۰۰۰ کلمه ۵ حرفی جذاب به عنوان واژگان هدف و نزدیک به ۶,۰۰۰ کلمه معتبر ۵ حرفی فارسی برای بررسی حدس‌ها.
- **مکانیک بازی استاندارد و دقیق:**
  - 🟩 **سبز:** حرف درست در جایگاه درست
  - 🟨 **زرد:** حرف درست در جایگاه دیگر
  - ⬛ **خاکستری:** حرفی که اصلاً در کلمه وجود ندارد
  - پشتیبانی از قانون تکرار حروف در وردل (بدون باگ رنگ زرد تکراری).
- **رابط کاربری و حس و حال بازی:**
  - فونت زیبای **وزیرمتن (Vazirmatn)** و طراحی راست‌به‌چپ (RTL).
  - انیمیشن‌های سه‌بعدی چرخش کاشی‌ها (3D Flip)، لرزش هنگام واژه اشتباه (Shake) و پرتاب پولک‌های شادی (Confetti) هنگام برد.
  - افکت‌های صوتی تعاملی با Web Audio API (صدای تایپ، افشای کاشی‌ها، ملودی پیروزی) همراه با دکمه قطع/وصل صدا بدون نیاز به فایل صوتی خارجی.
- **کیبورد هوشمند فارسی:**
  - کیبورد مجازی لمسی ۳۲ حرف فارسی + «آ» و دکمه‌های ثبت و پاک کردن.
  - اتصال به کیبورد فیزیکی: قابلیت تایپ مستقیم با زبان فارسی یا حتی کیبورد انگلیسی QWERTY (تبدیل خودکار به حروف فارسی برای راحتی کاربر).
- **جدول رده‌بندی ملی (Leaderboard):**
  - نمایش برترین حدس‌ها و رتبه‌های اول، دوم و سوم با مدال‌های 🥇، 🥈 و 🥉.
  - ثبت زمان صرف‌شده و تعداد حدس‌ها.
- **عضویت با ایمیل و کد تایید یکبار مصرف (Email OTP):**
  - بدون نیاز به رمز عبور (Passwordless).
  - استفاده از سیستم رایگان احراز هویت Supabase Auth.
- **اشتراک‌گذاری در اینستاگرام و X (Twitter):**
  - اشتراک فوری اموجی‌ها و متن در توییتر با یک کلیک.
  - **تولیدکننده کارت استوری اینستاگرام:** ساخت خودکار تصویر گرافیکی باکیفیت و جذاب روی Canvas مخصوص استوری اینستاگرام با قابلیت دانلود مستقیم.
  - اشتراک از طریق Web Share API در تلگرام، واتساپ و سایر اپلیکیشن‌ها.
- **انتخاب بعد از حدس:**
  - امکان شروع بازی جدید با کلمه تصادفی تازه
  - امکان خروج یا استراحت (بی‌خیال فعلاً)
  - ذخیره دائمی آمار در مرورگر حتی بدون اینترنت.

## 🗄️ پیکربندی Supabase (دیتابیس و OTP رایگان)

1. در سایت [supabase.com](https://supabase.com) یک پروژه رایگان جدید بسازید.
2. به بخش **SQL Editor** در پنل Supabase بروید و محتویات فایل [`supabase/schema.sql`](file:///Users/vahid/Workspace/Personal/wordle-farsi/supabase/schema.sql) را اجرا کنید تا جدول‌ها و قوانین امنیتی (RLS) ایجاد شوند.
3. در پنل Supabase به **Authentication -> Providers -> Email** بروید و مطمئن شوید فعال است (به صورت پیش‌فرض فعال و دارای سهمیه ماهانه رایگان ایمیل OTP است).
4. به **Project Settings -> API** بروید و مقادیر `Project URL` و `anon public key` را کپی کنید.
5. فایل `.env.local` را بسازید یا ویرایش کنید:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-public-key
   ```

## ☁️ استقرار در Vercel

1. کد را در یک مخزن GitHub قرار دهید:
   ```bash
   git add .
   git commit -m "Initial commit: Wordle Farsi"
   git remote add origin https://github.com/your-username/wordle-farsi.git
   git push -u origin master
   ```
2. وارد [vercel.com](https://vercel.com) شوید و دکمه **Add New Project** را بزنید.
3. مخزن را انتخاب کرده و در بخش **Environment Variables** دو متغیر زیر را اضافه کنید:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
4. دکمه **Deploy** را بزنید. پروژه ظرف چند ثانیه روی سرورهای جهانی ورسل مستقر می‌شود!
